# Stock Signal Alert

一个可在 Edge 或 Chrome 侧载的独立股票日线信号提醒扩展。它不隶属于或修改任何第三方扩展。

`v0.7.2` 详情页的日K信号点现在带有具体策略名，鼠标悬浮信号点可查看同一天触发的全部策略和方向。项目还包含转债自选、策略扫描、名称搜索和通知功能。

## 当前功能

- 自选 A 股代码及紧凑日线走势预览
- 每个标的独立启用 27 个股票策略
- 转债自选基础行情：代码、名称、现价、涨跌幅和成交量
- 标的详情页支持分时、日K、月K和鼠标悬浮详情
- 策略页扫描当前自选股并显示当前/最近信号
- 手动刷新和每 15 分钟后台检查
- 原生系统通知，按标的、策略和交易日去重

## 安装

1. 打开 `edge://extensions`。
2. 开启“开发人员模式”。
3. 选择“加载解压缩的扩展”，选中本目录。
4. 在扩展弹窗确认版本号为 `v0.7.2`。

## 数据与边界

日线来自公开行情接口，仅用于研究和提醒。策略信号不是投资建议，不包含自动下单或交易连接。

## 信号事件约定

后续接入交易系统时，每个信号可转换为：`symbol`、`strategy`、`direction`、`signalDate`、`price`、`detail`。本扩展目前只产生提醒，不会执行交易。
