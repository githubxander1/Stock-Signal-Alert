# Stock Signal Alert

一个可在 Edge 或 Chrome 侧载的独立股票日线信号提醒扩展。它不隶属于或修改任何第三方扩展。

`v0.7.4` 增加当天首次多空信号记录、历史查看和 CSV 导出；行情缓存继续支持代理/VPN不可用时回退到本地最近数据。

## 当前功能

- 自选 A 股代码及紧凑日线走势预览
- 每个标的独立启用 27 个股票策略
- 转债自选基础行情：代码、名称、现价、涨跌幅和成交量
- 标的详情页支持分时、日K、月K和鼠标悬浮详情
- 策略页扫描当前自选股并显示当前/最近信号
- 手动刷新和每 15 分钟后台检查
- 原生系统通知，按标的、策略和交易日去重
- 按标的、交易日和多空方向保存首次信号，历史页支持筛选与 CSV 导出（最多保留 5000 条）
- 行情持久缓存和东方财富/腾讯自动回退

## 安装

1. 打开 `edge://extensions`。
2. 开启“开发人员模式”。
3. 选择“加载解压缩的扩展”，选中本目录。
4. 在扩展弹窗确认版本号为 `v0.7.4`。

## 数据与边界

日线来自公开行情接口，仅用于研究和提醒。策略信号不是投资建议，不包含自动下单或交易连接。

## 信号事件约定

首次信号记录字段包括 `symbol`、`strategy`、`direction`、`signalDate`、`observedAt`、`price`、`detail`，可从“信号记录”页导出 CSV 用于回测复盘。记录基于后台每 15 分钟检查时实际观察到的日线策略结果；并非逐笔行情/分钟级触发时间，也不代表历史回测收益。本扩展不会执行交易。
